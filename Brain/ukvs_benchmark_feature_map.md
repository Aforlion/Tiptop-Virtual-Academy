# UK Virtual School Benchmark & Feature Parity Map

## Executive Summary
This document establishes `home.ukvirtualschool.com` (UK Virtual School) as the primary product benchmark for Tiptop Virtual Academy (TVA 2.0). TVA 2.0 adapts UKVS's online schooling model for the West African (Nigerian) and global Diaspora markets.

## Core Feature Ecosystem
1. **Public Conversion & Trust Funnel**
   - Virtual Open Days & Live Class Taster Sessions
   - Transparent Key Stage / Subject Fee Calculator
   - Parent Testimonials & Accreditation Badges (Cambridge / Pearson Edexcel alignment)

2. **Academic Delivery Modes**
   - Full-Time Online Schooling (Live classes + timetable)
   - Asynchronous / Flexible Homeschooling Support (Recorded backlogs + self-paced modules)
   - Supplementary / Single-Subject Modular Enrollment

3. **Parent & Student Portal Capabilities**
   - Multi-child family dashboard
   - Real-time timetable, attendance tracking, and grade reports
   - Integrated Google Workspace (Classroom & Meet)

4. **Phase Alignment (MVP vs Stage 2)**
   - **Stage 1 (MVP)**: Core IAM, Student/Parent Profile Association, British Curriculum Manifest Ingestion, Dual-Currency Checkout, Google Classroom Sync.
   - **Stage 2 (Growth)**: Virtual Open Day Booking, Live Taster Schedule, Interactive Timetable Telemetry, Modular Subject Add-ons, AI Companion.
